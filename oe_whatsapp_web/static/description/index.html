Overview

  • The WhatsApp Web Redirect module lets you reach any contact on WhatsApp in one click — straight from the Odoo contact form. No API keys, no webhooks, no third-party services, and no monthly fees.

    A clean WhatsApp button sits right next to the contact's mobile number. Click it and a small wizard opens with the contact and phone number already filled in. Type your message inside Odoo, then click Open WhatsApp Web — the chat opens on web.whatsapp.com with your message ready in the input box.

    It uses your own WhatsApp Web session, so there are no API costs and no risk of account bans from unofficial APIs. Works with both personal and WhatsApp Business numbers, and never interferes with any existing WhatsApp Business API module.

    Lightweight by design: one transient wizard, one inherited view, and one access rule. Install and use — no setup, no credentials, no provider account. Clean uninstall leaves no residual data.

    Developed and maintained by OdooElevate.

How It Works

Reach a contact on WhatsApp in three simple steps

Step 1: Open a Contact

Go to Contacts and open any contact that has a phone or mobile number. A green WhatsApp link appears right next to the number — inline with Call and SMS. Just click it.

Step 2: Type Your Message

A wizard opens with the contact and phone number pre-filled. Type your message and adjust the number if needed.

Step 3: Send on WhatsApp Web

Click Open WhatsApp Web. A new tab opens on web.whatsapp.com with the chat and message ready — press send and you're done.
